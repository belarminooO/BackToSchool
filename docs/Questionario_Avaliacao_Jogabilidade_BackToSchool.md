# Questionario de Avaliacao de Jogabilidade - BackToSchool

## Configuracao sugerida no Google Forms

- Titulo do formulario: `Questionario de Avaliacao de Jogabilidade - BackToSchool`
- Recolher emails: `Nao`
- Limitar a 1 resposta: `Opcional`
- Mostrar barra de progresso: `Sim`
- Embaralhar perguntas: `Nao`
- Perguntas obrigatorias: `1 a 17`
- Escala padrao: `1 = Muito fraco / 5 = Muito bom`

## Descricao do formulario

Obrigado por testares o `BackToSchool`.

Este questionario serve para avaliar a jogabilidade do prototipo, incluindo clareza dos objetivos, controlos, fase de quiz, corrida entre salas, interacoes entre jogadores, interface e eventuais problemas tecnicos.

O preenchimento demora cerca de `3 a 5 minutos`.

## Versao curta alternativa

Se quiseres um formulario mais rapido para testes frequentes, podes usar apenas estas 8 perguntas:

1. Foi facil perceber o objetivo do jogo?
2. Os controlos pareceram intuitivos?
3. A fase de quiz foi divertida?
4. O tempo das perguntas foi adequado?
5. O Vigia melhorou a experiencia?
6. A corrida entre salas foi divertida?
7. Como avalias a jogabilidade geral de 1 a 10?
8. O que melhorarias primeiro?

## Nota de utilizacao

Este formulario esta focado em `jogabilidade` e `experiencia do jogador`, nao na qualidade academica das perguntas do quiz. Se quiseres, pode valer a pena fazer um segundo formulario separado para avaliar:

- qualidade e relevancia das perguntas geradas por IA
- equilibrio das equipas
- clareza do sistema de pontuacao
- qualidade da experiencia multijogador
