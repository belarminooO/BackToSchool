Nota metodologica:
Os prompts abaixo foram selecionados por serem representativos do uso de ferramentas de inteligencia artificial generativa durante o desenvolvimento do jogo BackToSchool. A selecao privilegia pedidos associados a organizacao inicial de ideias, clarificacao tecnica, debugging, rede/multiplayer, NPC Vigia, geracao/interpretação de perguntas em JSON e apoio na documentacao. Algumas mensagens foram mantidas com a grafia original, para preservar fidelidade ao historico de utilizacao. Mensagens repetidas, puramente operacionais ou sem relevancia direta para o desenvolvimento foram excluidas.

Contexto: Instrucao de sistema usada para forcar a resposta da API em JSON puro.

Relevancia:
Esta instrucao foi usada para reduzir respostas invalidas e facilitar a leitura/interpretação do JSON gerado.

[GEM-02] Prompt principal para geracao de questionarios
Origem: Codigo do projeto
Ficheiro: 03_Implementacao/Quiz AI/Core Systems/GameManagers/GenerateQuizJSON/GenerateQuizJSON.cs
Contexto: Template de prompt usado para gerar rondas e perguntas do jogo com a API Gemini.
Prompt:
"Generate a trivia game with exactly {roundNumber} rounds.
Each round must have exactly {questionsPerRound} questions.
All questions must be at {difficulty} difficulty level.
Themes must ONLY come from the following list:
{csvData}

Rules:
- total_rounds must equal {roundNumber}
- round_id must start at 1 and increment sequentially
- question_id must start at 1 inside each round
- correct_option_index must be 0-based (0,1,2,3)
- IMPORTANT: You MUST randomize the correct_option_index for every question. The correct answer should NOT always be at index 0.
- CRITICAL: Every question must be fully self-contained. Do not use pronouns like 'he', 'she', or 'it' assuming the player knows the theme.
- CRITICAL: The question must explicitly state the subject (e.g., 'What year did World War 2 start?' instead of 'What year did it start?').
- Each question must have exactly 4 options
- Each option must contain a maximum of 1 to 3 words
- No duplicate questions

Return JSON in this EXACT structure:
{
  \"match_data\": {
    \"total_rounds\": number,
    \"rounds\": [
      {
        \"round_id\": number,
        \"theme\": \"string\",
        \"questions\": [
          {
            \"question_id\": number,
            \"text\": \"string\",
            \"options\": [\"string\", \"string\", \"string\", \"string\"],
            \"correct_option_index\": number
          }
        ]
      }
    ]
  }
}

Return raw JSON only. No markdown."
Relevancia:
Este e o prompt mais diretamente associado a geracao de questionarios no jogo. Define o numero de rondas, numero de perguntas, dificuldade, temas permitidos, estrutura JSON obrigatoria, indice da resposta correta e restricoes de qualidade das perguntas.
